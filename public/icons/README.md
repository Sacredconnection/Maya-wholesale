# Hero badge icon

Place the custom Hero badge icon in this folder with the following specification:

- Filename: `hero-authentic-tribes-01.svg`
- SVG artboard/viewBox: `48 × 48`
- Display size: `28 × 28 px`
- Recommended treatment: single-color artwork with a transparent background

The icon is displayed without an additional background or container before the
text “10 Authentic Tribes”.
