# Editorial page banners

Place the three final WebP files in this folder using these exact names:

- `about-banner.webp`
- `shipping-returns-banner.webp`
- `privacy-policy-banner.webp`

## Production specifications

- Canvas: **2400 × 900 px**
- Format: **WebP**
- Color profile: **sRGB**
- Recommended quality: **80–85%**
- Recommended maximum file size: **450 KB per image**
- Do not include titles, logos, buttons, or other text inside the image.

## Composition

- Keep the main subject in the **right-hand 40%** of the canvas.
- Leave the left-hand side calmer because the page title is positioned there.
- Keep important details away from the outer 8% of the image to allow responsive cropping.
- Extend the background around the subject so the image can crop safely on mobile screens.
- Check that the photograph remains usable below both a dark and a light translucent overlay.

The website automatically applies the appropriate overlay in dark and light themes.
