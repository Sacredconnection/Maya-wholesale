# Corporate details watermark

Place the SVG watermark for the **Corporate Details** card in this folder.

## Required file

- File name: `corporate-details-watermark.svg`
- Artboard: `320 x 320 px`
- SVG viewBox: `0 0 320 320`
- Background: transparent
- Color mode: RGB

Keep the artwork inside the artboard with approximately `16 px` of clear space
around the edges. Export the shapes as vector paths and do not bake opacity into
the SVG; the card will control the final watermark opacity in CSS.

The intended placement is the bottom-right corner of the card. When replacing the
artwork, keep this exact file name so the site reference does not need to change.
