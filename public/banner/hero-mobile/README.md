# Hero banners — mobile

O Hero possui dois slides. Crie uma versão mobile para cada imagem desktop atual:

- `hero-banner-mobile.webp` — versão mobile de `hero-banner.jpg`
- `hero-banner-01-mobile.webp` — versão mobile de `hero-banner-01.jpg`

## Dimensões

- Tamanho recomendado: 1080 × 1920 px
- Proporção: 9:16
- Formato: WebP
- Perfil de cor: sRGB
- Qualidade sugerida: 80–85%

## Área segura

- Preserve os 12% das bordas superior e inferior para variações de altura entre celulares.
- Mantenha a área esquerda e central com pouco contraste visual, pois recebe badge, título, descrição e CTA.
- Posicione pessoas, produtos e outros elementos importantes preferencialmente no lado direito ou no terço inferior.
- Não insira textos ou botões diretamente nas imagens.
