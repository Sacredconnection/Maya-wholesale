# Maya Wholesale conversion banner assets

This folder belongs exclusively to the lower wholesale account banner.

Replace these files while keeping their names:

1. `maya-wholesale-cta-banner-desktop.webp`
   - Desktop background.
   - Recommended canvas: 2560 × 840 px.
   - Keep the left side quiet enough for the logo, text, and button.

2. `maya-wholesale-cta-banner-mobile.webp`
   - Mobile background.
   - Recommended canvas: 1080 × 1350 px.
   - Keep the central area quiet enough for the content.

Do not include text, logos, or buttons in either background image. These files
are independent from the homepage hero assets in `/public/banner/maya-wholesale/`.
