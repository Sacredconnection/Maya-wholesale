# Retail sanctuary symbol

Coloque nesta pasta o símbolo SVG exibido acima do texto do banner de varejo.

Nome esperado do arquivo:

`maya-retail-symbol.svg`

Recomendações:

- Fundo transparente.
- Prancheta ajustada ao conteúdo, sem margens vazias excessivas.
- Preferencialmente utilize `viewBox` para preservar a responsividade.
- Não inclua textos ou imagens bitmap dentro do SVG.
- O componente será atualizado somente depois que o arquivo definitivo estiver nesta pasta.
