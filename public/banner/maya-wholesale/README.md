# Maya Wholesale hero assets

This folder is reserved for the homepage hero and the shared Maya Wholesale logo.

1. `logo-maya-wholesale.svg`
   - Format: SVG with a transparent background.
   - Artboard: 600 × 210 px (`viewBox="0 0 600 210"`).
   - Keep the artwork tightly fitted inside the artboard.
   - Use a light or colored logo treatment that remains legible over a dark background.

2. `maya-wholesale-banner-desktop.webp` — hero desktop background
   - Format: WebP.
   - Size: 1920 × 640 px.
   - Keep the left 55% dark and visually quiet for the text and button.
   - Place the main image or subject within the right 45%.
   - Do not include text, logos, or buttons in this background image.
   - Recommended maximum file size: 450 KB.

3. `maya-wholesale-banner-mobile.webp` — hero mobile background
   - Format: WebP.
   - Size: 1080 × 1350 px.
   - Keep the central and left areas dark and visually quiet for the content.
   - Keep the main subject close to the right edge and away from the logo, text, and button.
   - Do not include text, logos, or buttons in this background image.
   - Recommended maximum file size: 350 KB.

4. `maya-wholesale-banner-02.webp` — second rotating hero desktop background
   - Format: WebP.
   - Current size: 2560 × 590 px.
   - Keep the central area visually quiet for the overlaid text and button.
   - Keep important subjects away from the edges because the image uses `object-fit: cover`.
   - Do not include text, logos, or buttons in this background image.
   - Recommended maximum file size: 500 KB.

5. `maya-wholesale-banner-mobile-02.webp` — second rotating hero mobile background
   - Format: WebP.
   - Current size: 1080 × 1080 px.
   - Keep the central area visually quiet for the overlaid text and button.
   - Do not include text, logos, or buttons in this background image.
   - Recommended maximum file size: 350 KB.

The lower wholesale conversion banner uses separate assets in
`/public/banner/maya-wholesale-cta/`. Replacing files in this hero folder no
longer changes that banner.
