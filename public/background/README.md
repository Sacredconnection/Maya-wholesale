# Background global do site

Coloque a imagem nesta pasta com exatamente este nome:

`site-background.webp`

Especificações recomendadas:

- Dimensões: 2560 × 1440 px
- Proporção: 16:9
- Formato: WebP
- Peso ideal: até 600 KB
- Área principal: mantenha elementos importantes próximos ao centro, pois as bordas podem ser cortadas em telas de outras proporções

O site já referencia `/background/site-background.webp`. Ao adicionar ou substituir esse arquivo, o background global é atualizado automaticamente. A imagem cobre toda a tela sem distorção e permanece fixa durante a rolagem.
