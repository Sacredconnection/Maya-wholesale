# Wholesale format images

Place the packaging photos in this folder using these filenames:

- `retail-tins.webp` — photo for the Retail-Ready Tins card.
- `wholesale-bags.webp` — photo for the Wholesale Supply Bags card.

Recommended specifications:

- Dimensions: 1600 × 900 px (16:9).
- Format: WebP.
- Keep the packaging centered with enough space around it for responsive cropping.

The cards are permanently connected to these filenames. To update a photo,
replace the corresponding WebP file while keeping the same filename. No code
change is required; refresh the page to see the new image.
