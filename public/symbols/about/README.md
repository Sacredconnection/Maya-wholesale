# Símbolo da seção About Maya

Coloque nesta pasta o arquivo:

`about-maya-symbol-01.svg`

Especificação:

- Prancheta: **64 × 37,44 px**
- `viewBox`: **`0 0 64 37.44`**
- Preserve a proporção horizontal atual e mantenha o desenho centralizado
- Margem de segurança recomendada: **4 px** nas laterais
- Fundo transparente
- Não incluir texto, sombra ou caixa de fundo

O site exibe o símbolo com **80 px de largura** no mobile e **96 px de largura**
a partir de 640 px, sempre preservando a proporção. Se o arquivo ainda não
existir, nenhum espaço vazio permanece na seção.
