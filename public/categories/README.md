# Category card images

Add one **WebP** image for each card, using these exact filenames:

| Category | Filename | Dimensions |
| --- | --- | --- |
| Herbs | `herbs.webp` | 1600 x 1200 px |
| Aya Plants | `aya-plants.webp` | 1600 x 1200 px |
| Kratom | `kratom.webp` | 1600 x 1200 px |
| Rapéh | `rapeh.webp` | 1600 x 1200 px |
| Superfoods | `superfoods.webp` | 1600 x 1200 px |
| Incense | `incense.webp` | 1600 x 1200 px |

Use landscape images (4:3), with the focal subject near the center. Keep important details away from the outer 10% of each edge because the image is cropped responsively.
