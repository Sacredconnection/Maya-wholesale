# Lineage decorative bands

The lineage section uses a separate decorative band for each color theme:

- Dark theme: `lineage-decorative-band.webp`
- Light theme: `lineage-decorative-band-light.webp`

Recommended export for the light version:

- Dimensions: 1000 x 216 px
- Format: WebP with transparency
- Color profile: sRGB
- Keep the motif seamless at the left and right edges so it repeats horizontally
- Target file size: below 100 KB

The light image is automatically loaded from:

`/decorations/lineage-decorative-band-light.webp`
